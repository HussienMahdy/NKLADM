# بوابة بيانات إدارة نخل التعليمية — نسخة أولية قابلة للنشر

المشروع يحتوي على واجهة عربية لتسجيل الدخول، عرض وبحث البيانات، الفلاتر، تصدير CSV، واستيراد أوراق Excel الأربع إلى Supabase.

## مهم قبل الاستخدام
- هذا المشروع ليس موقعًا منشورًا بعد؛ يتطلب إنشاء مشروع Supabase ورفع الملفات إلى استضافة مثل GitHub Pages.
- لا ترفع ملف Excel الأصلي أو أي تصدير من بيانات الموظفين إلى مستودع GitHub عام.
- لا تضع `service_role` أو أي مفتاح سري في `index.html`. يستخدم الموقع مفتاح anon/publishable فقط مع RLS.
- تعطيل التسجيل العام وإنشاء حسابات المسؤولين يدويًا مطلوب. كل مستخدم مصرح له يملك صلاحيات متساوية في هذه النسخة.

## إعداد قاعدة البيانات
1. أنشئ مشروعًا على https://supabase.com/
2. افتح SQL Editor ونفّذ محتويات `schema.sql`.
3. من Authentication > Settings عطّل التسجيل العام (Allow new users to sign up).
4. من Authentication > Users أنشئ حسابًا مستقلًا لكل مسؤول.
5. من Project Settings > API انسخ Project URL ومفتاح anon/publishable.
6. افتح `index.html` محليًا أو بعد النشر، وضع URL والمفتاح في شاشة الإعداد.
7. سجّل الدخول، ثم استخدم «استيراد جميع الأوراق» واختر ملف Excel الأصلي من جهازك.

## النشر على GitHub Pages
1. أنشئ مستودعًا خاصًا على GitHub وارفع `index.html` و`schema.sql` و`README.md` فقط.
2. من Settings > Pages فعّل النشر من `main` و`/(root)`.
3. لا ترفع ملف Excel أو ملفات CSV الناتجة. تنبيه: جعل المستودع خاصًا لا يغني عن حماية قاعدة البيانات عبر RLS.

## البيانات والأوراق
يتوقع البرنامج الأوراق التالية:
- `ادارة نخل بالمدارس`
- `المنتدبين`
- `الاجازات الخاصة`
- `محاكمة تأديبية`

يبحث البرنامج عن صف العناوين في أول 20 صفًا، ثم يخزن جميع الحقول غير الفارغة في JSONB، لذلك يحتفظ بالحقول الموجودة في صف العناوين. بعض الفلاتر تظهر فقط عند اكتشاف عمود مناسب. أسماء الأوراق يجب أن تطابق الأسماء المذكورة أعلاه.

## تنبيه تقني
عملية الاستيراد تستبدل سجلات الأقسام الأربعة الحالية. يوصى بتنفيذ الاستيراد الأولي من اتصال موثوق وبعد التأكد من وجود نسخة أصلية محفوظة بشكل آمن. النسخة الأولية تعرض سجلات الأقسام لجميع المستخدمين المصادق عليهم بنفس الصلاحيات، كما طلب صاحب المشروع.
